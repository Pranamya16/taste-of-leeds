# Contributing to Taste of Leeds

Thank you for your interest in helping Taste of Leeds.

## Before contributing

- Read the README and content guidelines.
- For substantial changes, open an issue first so the work can be discussed.
- Keep changes small and focused.
- Do not commit passwords, API keys, private data or `.env.local`.

## Suggested workflow

1. Create or choose a GitHub Issue describing the task.
2. Create a branch for your change.
3. Make the change locally.
4. Run the project and test the affected page or feature.
5. Commit with a clear message.
6. Open a Pull Request describing what changed and how it was tested.

## Content contributions

Restaurant recommendations should include the business name, location, cuisine or regional tradition, and a useful reason for recommending it. Do not submit content or images you do not have permission to share.

## Pull Request checklist

- [ ] The change has a clear purpose.
- [ ] The affected page or feature was tested.
- [ ] No secrets or private information were added.
- [ ] Text and images are appropriate to publish.
- [ ] Documentation was updated if needed.
