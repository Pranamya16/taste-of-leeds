# Taste of Leeds

**Discover the world, one Leeds food spot at a time.**

Taste of Leeds is a community-powered food discovery website focused on the cultures, stories and experiences behind food in Leeds, UK.

The aim is to help people discover restaurants and food spots through community recommendations—not just popularity or star ratings.

## Project status

🚧 **Early-stage project.** The first version is being planned and built. Restaurant listings, reviews and other examples should be treated as sample content until checked and approved.

## What we want to build

- Browse food spots by cuisine and neighbourhood.
- View restaurant profiles with addresses, photos, dishes and useful details.
- Read community recommendations and personal food stories.
- Let members suggest food spots and submit reviews.
- Highlight cultural context respectfully, without claiming that one person can decide what is or is not authentic.
- Give the site owner tools to review submissions and manage reported content.

## What makes Taste of Leeds different?

We want to make room for context. A review might explain:
- Which dish the reviewer recommends.
- What they enjoyed about the flavours or preparation.
- Their personal connection to the cuisine, if they choose to share it.
- Whether the dish reminds them of a regional or family tradition.
- What visitors who are new to the cuisine might want to try.

Cultural connection is personal and varied. The site should present perspectives and experiences, not issue a universal authenticity score.

## Planned technology

The initial technical plan is:

- **Next.js** — website framework.
- **React** — user interface.
- **Tailwind CSS** — styling.
- **Supabase** — database and, later, user accounts.
- **Vercel** — hosting and deployment.
- **GitHub** — source code and project planning.

These choices may change as the project develops.

## Getting started

The first build will be developed locally and pushed to GitHub.

1. Install a current LTS version of Node.js: https://nodejs.org/
2. Install Visual Studio Code: https://code.visualstudio.com/
3. Create or open the project repository on GitHub.
4. Follow the setup instructions in `docs/GETTING_STARTED.md`.
5. Keep passwords and API keys out of GitHub. Use `.env.local` for local secrets.

## How to contribute

At the beginning, contributions may be coordinated by the project owner. If you spot an issue or have an idea, open a GitHub Issue with a clear description.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting code or content.

## Important principles

1. Be respectful of cultures and regional differences.
2. Make it clear who is sharing an opinion or experience.
3. Verify practical details such as addresses and opening hours before publishing.
4. Obtain permission for photos and other content you do not own.
5. Do not publish private information or discriminatory, abusive or misleading content.
