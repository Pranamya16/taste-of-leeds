# First-version roadmap

## Phase 0 — Project setup
- [ ] Create GitHub repository.
- [ ] Install Node.js and VS Code.
- [ ] Create the Next.js app.
- [ ] Run the starter app locally.
- [ ] Push the project to GitHub.

## Phase 1 — Visual foundation
- [ ] Confirm the name, logo and tagline.
- [ ] Apply the colour palette and typography.
- [ ] Build responsive navigation.
- [ ] Build the homepage hero and search area.
- [ ] Add cuisine discovery sections.
- [ ] Check mobile and desktop layouts.

## Phase 2 — Food-spot directory
- [ ] Create sample food-spot data clearly marked as sample.
- [ ] Build food-spot cards.
- [ ] Build a directory page.
- [ ] Add cuisine and neighbourhood filters.
- [ ] Build an individual food-spot page.
- [ ] Verify real listing details before publishing.

## Phase 3 — Community
- [ ] Design the recommendation form.
- [ ] Add dish recommendations and written experiences.
- [ ] Add reviewer context as optional self-description.
- [ ] Add review submission and approval status.
- [ ] Add reporting and correction process.
- [ ] Add user accounts only when needed.

## Phase 4 — Database and safety
- [ ] Set up Supabase.
- [ ] Create food-spot, cuisine and review tables.
- [ ] Configure database access policies.
- [ ] Validate and moderate user submissions.
- [ ] Add privacy and community guidelines.

## Phase 5 — Launch
- [ ] Test forms and filters.
- [ ] Check accessibility and mobile usability.
- [ ] Check links, addresses and opening hours.
- [ ] Add privacy and contact information.
- [ ] Deploy through Vercel.
- [ ] Invite a small group to test and give feedback.

**Rule:** Finish and test each phase before adding more features. The checklist is a plan, not a claim that these features already exist.
