# Taste of Leeds — clickable prototype

A beginner-friendly, static website prototype for a community-powered Leeds food discovery project.

## Run it

**The easiest way:** open `index.html` in a modern web browser. No installation or coding setup is required.

Alternatively, open this folder in Visual Studio Code and use the Live Server extension.

## What's included

- Responsive homepage and mobile navigation.
- Search by spot name, dish, cuisine, area or story.
- Combined cuisine and Leeds-area filters, with a clear-filters action.
- Clickable restaurant profiles with a menu dish and factual context.
- Leeds restaurants with addresses and map searches built from their business name and full street address.
- Restaurant website and menu source links in each profile.
- Recommendation form with a first-hand experience prompt. New entries appear as pending review for the current browser session only.
- Keyboard focus styles, labelled controls and accessible dialog feedback.
- About and community story sections.

## Important prototype limitations

- Restaurant names, menu examples and addresses are linked to business websites or local listings. Check current details before travelling; the prototype does not verify live opening status.
- Google Maps links search for the restaurant name and full address; Google Maps may still change how it resolves a result.
- The recommendation form does not send data to a server or persist it after the page session. Suggestions appear locally as pending review.
- Listings are researched examples, not community recommendations or endorsements.
- There is no database, login, admin panel or live map yet.
- Fonts load from Google Fonts when internet access is available; fallback fonts are included.
